# 项目级技能库

本目录保存可复用的项目级技能，统一约定如下：

- 路径：`.agents/skills/<skill-name>/`
- 主入口：`SKILL.md`
- 附属脚本、模板、资源文件：与 `SKILL.md` 放在同一目录

  入口：`.agents/skills/UI-UX-PRO-MAX/SKILL.md`
